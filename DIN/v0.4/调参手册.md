# PCVRHyFormer v9.0 参数调参手册

## 一、模型结构参数（影响容量、推理速度）

| 参数 | 默认值 | 含义 | 值 ↑ 效果 | 值 ↓ 效果 | 建议范围 |
|------|--------|------|-----------|-----------|----------|
| `--d_model` | 64 | 主干隐藏维度（所有 token 的维度） | 模型容量 ↑，参数量 ↑↑，可能过拟合 | 模型容量 ↓，推理加速 | 64 / 128 / 256 |
| `--emb_dim` | 64 | 每个 Embedding 表输出维度（投影前） | 特征表达 ↑，参数量 ↑ | 特征表达 ↓，省显存 | 32 / 64 / 128 |
| `--num_queries` | 1 | 每个序列域生成的 Query Token 数量 | 序列信息提取 ↑，T 变大 | 聚合更紧凑 | 1 / 2 / 4 |
| `--num_hyformer_blocks` | 2 | HyFormer Block 堆叠层数 | 特征交叉深度 ↑，可能过拟合 | 训练更快 | 1 / 2 / 3 |
| `--num_heads` | 4 | 多头注意力头数（必须整除 d_model） | 多角度关注 ↑ | 每头维度 ↑ | 4 / 8 |
| `--hidden_mult` | 4 | FFN 内部维度 = d_model × hidden_mult | 非线性表达 ↑ | 参数量 ↓ | 2 / 4 / 8 |
| `--dropout_rate` | 0.01 | Backbone Dropout 率 | 正则化 ↑ | 欠拟合风险 | 0.01 / 0.05 / 0.1 |
| `--user_ns_tokens` | 0 | 用户侧 NS Token 数（0=自动=group数） | 用户特征细分 ↑ | 更紧凑 | 0（自动）或手动设 |
| `--item_ns_tokens` | 0 | 物品侧 NS Token 数（0=自动=group数） | 物品特征细分 ↑ | 更紧凑 | 0（自动）或手动设 |

---

## 二、开关类结构参数

> 用 `--xxx` 开启，`--no_xxx` 关闭

| 参数 | 默认值 | 含义 | 开启效果 |
|------|--------|------|----------|
| `--use_target_attention` | **True** | DIN 式目标感知注意力 + item 条件查询生成 | ✅ 推荐保持开启，核心模块 |
| `--use_time_buckets` | **True** | 序列时间戳离散化 Embedding | ✅ 引入时间信息 |
| `--use_calendar_time` | **True** | 小时/星期 Embedding + sin-cos 循环特征 | ✅ 捕捉周期性行为模式 |
| `--use_time_span_buckets` | **True** | 行为间隔时长离散 Embedding | ✅ 捕捉行为节奏 |
| `--use_rope` | **False** | RoPE 旋转位置编码 | 序列位置感知 ↑，显存微增 |
| `--seq_causal` | **False** | LongerEncoder 因果 mask（只看历史） | 防止信息泄露（推荐开） |
| `--use_se_net` | **False** | SE-Net 特征门控（对 NS Token 加权） | 自适应特征选择，可试 |
| `--use_ns_self_attn` | **False** | NS Token 间自注意力（特征交叉） | 非序列特征间交互 ↑ |
| `--use_ns_output_fusion` | **False** | 最终 NS Token 融合到输出 | 非序列特征利用率 ↑ |
| `--use_temporal_bias` | **False** | 注意力中按时间衰减的偏置 | 时间感知更精确 |
| `--use_time_gap` | **False** | 行为间时间间隔 Embedding | 捕捉行为节奏 |

## 三、序列编码器参数

| 参数 | 默认值 | 含义 | 说明 |
|------|--------|------|------|
| `--seq_encoder_type` | `transformer` | 序列编码器类型 | `swiglu` = 仅 FFN（无注意力）<br>`transformer` = 标准自注意力<br>`longer` = Top-K 压缩编码器 |
| `--seq_top_k` | 50 | LongerEncoder 保留的最近 token 数 | 仅 `--seq_encoder_type=longer` 时生效，值越大保留越多历史 |
| `--rank_mixer_mode` | `full` | RankMixer 模式 | `full` = Token Mixing + 逐 Token FFN<br>`ffn_only` = 仅逐 Token FFN<br>`none` = 恒等映射 |

---

## 四、训练超参数

| 参数 | 默认值 | 含义 | 值 ↑ 效果 | 值 ↓ 效果 | 建议范围 |
|------|--------|------|-----------|-----------|----------|
| `--lr` | 1e-4 | 稠密参数学习率（AdamW） | 收敛快，可能震荡 | 收敛慢但稳定 | 1e-5 ~ 1e-3 |
| `--batch_size` | 256 | 训练/验证批大小 | 梯度稳定，显存 ↑ | 梯度噪声大，显存 ↓ | 128 / 256 / 512 |
| `--num_epochs` | 999 | 最大训练轮数 | 足够收敛 | 欠拟合 | 通常 EarlyStopping 提前终止 |
| `--patience` | 5 | Early Stopping 耐心值 | 容忍更多轮不提升 | 更快停止 | 3 / 5 / 10 |
| `--weight_decay` | 0.01 | AdamW 权重衰减 | 正则化 ↑ | 可能欠拟合 | 0.001 ~ 0.1 |
| `--warmup_steps` | 0 | 线性 LR 预热步数 | 初期训练更稳定 | 无预热 | 100 ~ 1000 |
| `--lr_schedule` | `none` | LR 调度策略 | `cosine` = 余弦退火（需配合 warmup） | `none` = 恒定 | `none` / `cosine` |

---

## 五、损失函数参数

| 参数 | 默认值 | 含义 | 说明 |
|------|--------|------|------|
| `--loss_type` | `bce` | 损失类型 | `bce` = BCEWithLogits<br>`focal` = Focal Loss<br>`bce_pairwise` = BCE + 成对排序损失 |
| `--focal_alpha` | 0.1 | Focal Loss 正类权重 | 仅 `loss_type=focal`，值越大正样本权重越大 |
| `--focal_gamma` | 2.0 | Focal Loss 聚焦参数 | 仅 `loss_type=focal`，值越大越关注难样本 |
| `--pairwise_lambda` | 0.05 | 成对排序损失权重 | 仅 `loss_type=bce_pairwise` |
| `--label_smoothing` | 0.0 | 标签平滑 ε | 0 = 禁用，0.01 ~ 0.1 可缓解过拟合 |

---

## 六、稀疏优化器参数

| 参数 | 默认值 | 含义 | 说明 |
|------|--------|------|------|
| `--sparse_lr` | 0.05 | 稀疏参数学习率（Adagrad） | Embedding 表专用 |
| `--sparse_weight_decay` | 0.0 | 稀疏参数权重衰减 | 通常保持 0 |
| `--reinit_sparse_after_epoch` | 1 | 从第 N 轮起重置高基数 Embedding | 防高基数特征过拟合 |
| `--reinit_cardinality_threshold` | 0 | 重置的基数阈值 | 0 = 永不重置；设为 10000 则 vocab > 10000 的特征每轮重置 |

---

## 七、Embedding 构建控制

| 参数 | 默认值 | 含义 | 值 ↑ 效果 |
|------|--------|------|-----------|
| `--emb_skip_threshold` | 0 | 超此基数的特征不建 Embedding（用零向量） | 省显存，但丢失信息 |
| `--seq_id_threshold` | 10000 | 超此基数的序列特征加额外 Dropout | 防过拟合 |
| `--hash_bucket_size` | 100000 | Hash Embedding 桶数 | 0 = 禁用；用于超高基数特征 |

---

## 八、数据管道参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--seq_max_lens` | `seq_a:256,seq_b:256,seq_c:512,seq_d:512` | 每域序列截断长度 |
| `--train_ratio` | 1.0 | 训练数据使用比例（取前 N%） |
| `--valid_ratio` | 0.1 | 验证集比例（取尾部） |
| `--buffer_batches` | 20 | Shuffle 缓冲区大小（以 batch 为单位） |
| `--num_workers` | 16 | DataLoader 工作进程数 |
| `--seed` | 42 | 随机种子 |
| `--precision` | `auto` | 训练精度：`auto` / `fp32` / `bf16` |
| `--ema_decay` | 0.0 | EMA 衰减率（0 = 禁用，推荐 0.999） |
| `--ns_tokenizer_type` | `rankmixer` | NS Tokenizer 类型：`group` = 每组一 Token，`rankmixer` = 拼接后分块 |
| `--ns_groups_json` | `ns_groups.json` | NS 分组配置文件路径 |

##   建议调参优先级

### 第 1 优先：影响最大

```
--lr 1e-4 → 5e-4 / 1e-3        # 学习率是最重要的超参
--d_model 64 → 128 / 256         # 增大模型容量
--num_hyformer_blocks 2 → 3      # 加深特征交叉
```

### 第 2 优先：开关新模块

```
--use_se_net                     # SE-Net 特征门控，自适应加权
--use_ns_self_attn               # NS Token 间自注意力，特征交叉
--use_temporal_bias              # 时间衰减偏置
--use_rope                       # RoPE 旋转位置编码
--use_ns_output_fusion           # NS Token 融合到输出
--use_time_gap                   # 行为间隔 Embedding
```

### 第 3 优先：损失函数

```
--loss_type focal --focal_alpha 0.25 --focal_gamma 2.0    # Focal Loss 处理不平衡
--loss_type bce_pairwise --pairwise_lambda 0.05            # 加入排序信号
--label_smoothing 0.01                                     # 标签平滑
```

### 第 4 优先：训练技巧

```
--lr_schedule cosine --warmup_steps 500    # 余弦退火 + 预热
--ema_decay 0.999                           # 指数移动平均
--dropout_rate 0.05                         # 增大 Dropout 防过拟合
--weight_decay 0.05                         # 增大权重衰减
```

##   典型调参命令示例

```bash
# 基线（v9.0 默认）
python train.py

# 加大模型
python train.py --d_model 128 --num_hyformer_blocks 3 --num_heads 8

# 加 Focal Loss
python train.py --loss_type focal --focal_alpha 0.25 --focal_gamma 2.0

# 开全部新模块 + 余弦退火
python train.py \
    --d_model 128 \
    --num_hyformer_blocks 3 \
    --use_se_net \
    --use_ns_self_attn \
    --use_temporal_bias \
    --use_rope \
    --loss_type focal --focal_alpha 0.25 --focal_gamma 2.0 \
    --lr_schedule cosine --warmup_steps 500 \
    --ema_decay 0.999 \
    --label_smoothing 0.01
```
