B Sequence Embedding（序列特征 → Token）

def _embed_seq_domain(self, seq, embs, proj, is_id, emb_index, time_bucket_ids):
    B, S, L = seq.shape  # (B, S_features, L_length)

    # 1. 每个特征列独立 Embedding
    for i in range(S):
        e = emb(seq[:, i, :])          # (B, L, E)
        if is_id[i] and training:
            e = dropout(e)              # 高基数 ID 特征额外 dropout

    # 2. 拼接 → 投影
    cat_emb = cat(all_embs, dim=-1)   # (B, L, S*E)
    token   = GELU( proj(cat_emb) )       # (B, L, D)  via Linear(S*E→D)

    # 3. 加时间间隔 Embedding
    token = token + time_embedding(time_bucket_ids)  # (B, L, D)
核心设计: 序列中每个位置有 S 个特征字段（如 item_id, cate_id, brand_id...）， 每个字段独立过 Embedding 后拼接，再通过一个 Linear 投影到 D 维。 时间桶 Embedding 作为位置编码的替代方案直接相加。

D MultiSeqHyFormerBlock（核心计算单元）

每个 Block 对 每个序列域独立 做序列进化 + 查询解码，然后将 全部 Q Token + NS Token 拼接 进行联合混合。 这是模型的核心创新：独立处理 + 联合混合。

for each block in self.blocks:       # 重复 2 次

  # ── 阶段 1: 序列进化 (Per-Seq, 独立并行) ──
  for i in range(S):
      seq_i, mask_i = seq_encoder[i](seq_i, mask_i)

  # ── 阶段 2: 查询解码 (Per-Seq, 独立并行) ──
  for i in range(S):
      q_i = cross_attn[i](q_i, seq_i, mask_i)  # Q attend Seq

  # ── 阶段 3: Token 融合 ──
  combined = cat([q_1, ..., q_S, ns_tokens], dim=1)

  # ── 阶段 4: RankMixer 查询增强 (跨 Token 交互) ──
  boosted  = RankMixerBlock(combined)

  # ── 阶段 5: 拆分回原结构 ──
  q_1, ..., q_S, ns_tokens = split(boosted)

6. Rotary Position Embedding (RoPE) — 可选

当 use_rope=True 时启用。预计算 cos/sin 缓存，在 Attention 中对 Q/K 施加旋转位置编码。

  • 参数: dim=head_dim=16, base=10000, max_seq_len=2048
  • 应用位置: Self-Attention (Q+K) / Cross-Attention (仅 K)
  • 缓存策略: 初始化时预计算 max_seq_len 长度的 cos/sin，forward 时切片使用，兼容 torch.compile
def apply_rope_to_tensor(x, cos, sin):
    # x: (B, num_heads, L, head_dim)
    # cos, sin: (1, L, head_dim)
    return x * cos + rotate_half(x) * sin
