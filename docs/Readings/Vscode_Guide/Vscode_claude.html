Stage 01 · Prerequisite

检查 / 安装 Node.js

⏱ 约 1 分钟（已有 Node 则跳过）

Claude Code CLI 依赖 Node.js 运行环境。先在终端检查你是否已经安装：

~/ — zsh
$ node -v
v24.15.0 # 看到版本号即可，v18+ 都行

如果提示 command not found，需要先安装 Node.js：

安装 Node.js（仅当未安装时）
# macOS · 推荐用 Homebrew
$ brew install node
# 没有 brew 的话，先装 brew
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
提示 · Windows / Linux

Windows 用户去 nodejs.org 下载安装包；Linux 用 apt install nodejs 或 nvm。

✓
检查点 1

运行 node -v 能看到版本号（v18 或更高）才算通过。

2
Stage 02 · CLI Install

安装 Claude Code CLI

⏱ 约 30 秒

用 npm（Node.js 的包管理器）全局安装 Claude Code：

~/ — zsh
$ npm install -g @anthropic-ai/claude-code
changed 2 packages in 3s # 这样就成功了
✓
检查点 2

命令执行后没有报错就行。可选验证：运行 claude --version 看到版本号。

3
Stage 03 · VSCode Extension

安装 VSCode 扩展（关键 · 容易装错）

⏱ 约 1 分钟

打开 VSCode，按 Cmd + Shift + X（Windows 是 Ctrl + Shift + X）打开扩展面板，搜索 Claude Code。

高频踩坑警告

搜索结果里会有十几个名字相似的扩展，绝大部分都是第三方的

必须装的是第一个 —— 发布者是 Anthropic（带蓝色认证勾），下载量 13M+ 的那个。

千万不要装：Chat for Claude Code、Claude Code Assist、Claude Code YOLO、Kiro for Claude、Claude Code UI、Claude Code Theme ... 这些都是第三方包装。

  1. 找到发布者为 Anthropic 的 Claude Code 扩展
  2. 点 Install 按钮
  3. 安装完成后会自动打开 "Get started with Claude Code" 引导页
✓
检查点 3

VSCode 顶部标签栏出现 ✳ Claude Code 的橙色图标。如果没看到，按 Cmd + Shift + P 打开命令面板，输入 "Claude Code" 找入口。

4
Stage 04 · Open Project & Login

打开项目 + 登录账号

⏱ 约 2 分钟

4.1 打开项目文件夹 — VSCode 菜单：File → Open Folder，导航到你 clone 的 TAAC2026/ 根目录。

4.2 启动 Claude Code 面板 — 用以下任意一种方式：

  1. 按快捷键 Cmd + Escape（Mac）或 Ctrl + Escape（Win）
  2. 或点击 VSCode 右上角的橙色 ✳ Claude Code 图标
  3. 或在命令面板（Cmd + Shift + P）输入 Claude Code: Focus

4.3 登录 — 第一次打开会弹出登录界面，选择最上面的橙色按钮 "Claude.ai Subscription"（Pro / Max / Team 用户都选这个）。它会跳转到浏览器完成 OAuth 授权。

注意

另外两个按钮 "Anthropic Console" 是按 API 用量付费的，"Bedrock / Foundry / Vertex" 是企业方案。我们都不用，认准最上面的橙色按钮。

✓
检查点 4

登录成功后会回到 VSCode，Claude Code 面板显示 "What to do first? Ask about this codebase or we can start writing code."，底部出现输入框 "Ask Claude to edit..."。

5
Stage 05 · Verify

验证：让 Claude Code 读你的代码

⏱ 约 30 秒

在 Claude Code 输入框里发送下面这条消息，验证它真的能读取你的项目：

Claude Code · 测试消息
你好，请告诉我你现在能看到哪些项目文件？

如果一切正常，Claude Code 会：

  1. 自动运行 ls -la 之类的命令读取你的项目根目录
  2. 列出 Hyformer/、Interformer/、datasetAnalysis/、docs/、README.md 等
  3. 询问你想深入了解哪个目录
✓
最终检查点

看到 Claude Code 用中文/英文列出了你 TAAC2026/ 下的真实文件 → 大功告成。

Common Pitfalls · 容易踩的坑

避坑指南

这些是我们部署过程中真实遇到的问题，列出来让你们少走弯路。

01

把 GitHub Copilot Chat 当成了 Claude Code

VSCode 自带的 Copilot 聊天面板长得很像 Claude Code（都是右侧的 "Chat" 面板），但里面的模型列表是 GPT-4.1、GPT-4o、GPT-5 mini，不是 Claude。

认准顶部 ✳ Claude Code 橙色图标的那个标签页，模型应该显示 Claude Opus / Sonnet。

02

装了第三方"Claude" 扩展

搜索 "Claude Code" 会出现十几个结果，第一个之外几乎都是第三方（Andre Pimenta、CodeFlow Studio、Aura Technologies、黑色白云 等）。

只装发布者为 Anthropic 的那一个，下载量 13M+ 是它的特征。

03

登录时点错了按钮

登录界面有三个选项：Claude.ai Subscription / Anthropic Console / Bedrock。后两个会让你按 API 量付费，跟你的 Pro/Max 订阅无关。

永远选最上面的橙色 Claude.ai Subscription。

04

找不到 Claude Code 的入口

安装扩展后有时左侧边栏不会立即出现图标，找不到入口。

三个备选方案：① Cmd + Escape 快捷键 ② 命令面板（Cmd + Shift + P）输入 "Claude Code" ③ 终端直接运行 claude。

05

npm install 报权限错误

Mac 上有时 npm install -g 会报 EACCES permission denied。

前面加 sudo：sudo npm install -g @anthropic-ai/claude-code，输入开机密码即可。

完成清单

装完之后逐项核对，全部打勾就说明你已经准备好开始用 Claude Code 改 TAAC2026 项目了。

  • Node.js 在终端运行 node -v 能看到版本号
  • Claude Code CLI 通过 npm 全局安装完成
  • VSCode 扩展 安装了 Anthropic 官方 发布的那一个（不是第三方）
  • 项目已打开 在 VSCode 里打开了 TAAC2026/ 根目录
  • 账号已登录 通过 "Claude.ai Subscription" 用 Max / Pro 账号授权完成
  • 验证通过 Claude Code 能读到你本地的项目文件列表
