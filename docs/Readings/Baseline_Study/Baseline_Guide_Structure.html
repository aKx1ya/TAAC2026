学习哲学

理解一个深度学习系统，本质上是理解三件事：数据怎么进去（dataset.py）、模型怎么处理（model.py）、怎么变聪明（trainer.py）。下面五个阶段就是沿着这条线逐步深入。

核心原则

每个阶段都在 Claude Code 里边问边学，不是只读文档。让 Claude Code 打开真实代码，逐行给你解释，你提问它回答——这是最高效的学习方式。

Phase 01 · Data Pipeline

数据怎么进去的？

⏱ 建议时间：1-2 小时 · 核心文件：dataset.py

目标：理解 100 万条 Parquet 数据的 120 列怎么被加载、分组、填充、变换，最终变成模型能"吃"的张量（Tensor）。

1.1 理解数据的全貌 Claude Code

先让 Claude Code 给你画一个全景图：120 列被分成哪几大类？每类有多少列？

请打开 Hyformer/HyFormer-v0.0/dataset.py，解释一下这个文件做了什么。 特别是： 1. 120列数据被分成了哪几大类？（用户特征、物品特征、序列等） 2. 每一类在代码里对应哪个变量名？ 3. FeatureSchema 这个类是干什么的？ 请用通俗的中文解释，我是非CS背景。
1.2 理解序列数据的处理 Claude Code

4 个行为序列（seq_a/b/c/d）是整个模型最复杂的输入。搞懂它们怎么从变长列表变成固定长度的张量。

在 dataset.py 里，4个行为序列（domain_a_seq, domain_b_seq, domain_c_seq, domain_d_seq）是怎么被处理的？ 1. 每个序列包含哪些列？ 2. 变长序列怎么被截断和填充（padding）？ 3. seq_max_lens 参数（a:256, b:256, c:512, d:512）是什么意思？ 4. time_bucket 是怎么算的？
1.3 理解 DataLoader 的工作方式 Claude Code

了解数据怎么被分批次（batch）送给模型，以及训练集/验证集怎么划分。

在 dataset.py 的 get_pcvr_data 函数里： 1. 训练集和验证集是怎么划分的？（valid_ratio=0.1 是什么意思？） 2. 一个 batch 的数据长什么样？包含哪些字段？ 3. buffer_batches=20 的 shuffle 机制是怎么工作的？ 4. collate_fn 做了什么？
✓

阶段检查点：你能用自己的话说出"一条样本包含哪些信息"和"一个 batch 是怎么组装的"，就算通过了。

Phase 03 · Training Mechanics

模型怎么"变聪明"的？

⏱ 建议时间：1-2 小时 · 核心文件：trainer.py + utils.py

目标：理解训练循环——模型怎么从"瞎猜"变成"越来越准"。这部分决定了你后续能做哪些训练技巧的改进。

3.1 训练循环的骨架 Claude Code

理解 train_one_epoch 里的每一步：取数据 → 模型预测 → 算损失 → 更新参数。

请打开 trainer.py 的 train_one_epoch 方法： 1. 一个 training step 具体做了哪些事？按顺序列出。 2. loss.backward() 和 optimizer.step() 分别在干什么？ 3. 为什么有两个 optimizer（sparse_optimizer + dense_optimizer）？ Adagrad 和 AdamW 各自负责哪些参数，为什么要分开？ 4. gradient clipping (max_norm=1.0) 是干什么的？
3.2 验证和早停 Claude Code

理解模型怎么知道自己"学好了"或"学过头了"。

请解释 trainer.py 里的 evaluate 方法和 EarlyStopping 类： 1. 验证（validation）和训练有什么区别？为什么要分开？ 2. AUC 是怎么算的？它衡量的是什么？ 3. EarlyStopping 的 patience=5 意味着什么？ 4. 模型什么时候保存 checkpoint？保存了什么？
3.3 损失函数 Claude Code

理解 BCE Loss 和 Focal Loss 的区别——这直接影响模型学什么。

请解释 utils.py 里的 sigmoid_focal_loss： 1. BCE Loss 和 Focal Loss 分别是什么？用考试打分的类比。 2. alpha 和 gamma 两个参数分别控制什么？ 3. 为什么在类别不平衡时 Focal Loss 可能更好？ 4. baseline 用的是哪个 loss？（看 run.sh 和 train.py 的默认值）
✓

阶段检查点：你能解释"为什么 Loss 会震荡"（sparse_lr=0.05 太大）以及"为什么 AUC 会 plateau"（模型停止学新东西）——这些和训练曲线上看到的现象完全对应。
