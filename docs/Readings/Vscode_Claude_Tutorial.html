01 安装 VS Code

如果你已经有 VS Code，直接跳到 Step 2。

下载安装

打开 https://code.visualstudio.com → 下载 Mac 版（Apple Silicon 或 Intel）→ 解压后拖到 Applications 文件夹。

安装命令行工具（推荐）

打开 VS Code → 按 Cmd + Shift + P → 输入 Shell Command: Install 'code' command in PATH → 回车。之后你就可以在 Terminal 里用 code . 打开文件夹了。

安装 Python 扩展

左侧边栏点击扩展图标（四个方块）→ 搜索 Python → 安装微软官方的 Python 扩展。这个提供代码高亮、智能提示、调试器。

02 安装 Claude Code 扩展

让 Claude 直接在你的编辑器里帮你读代码、改代码、跑命令。

安装方式

  • VS Code 左侧栏 → 扩展（Extensions）→ 搜索 Claude Code
  • 找到 Anthropic 官方出品的 Claude Code → 点击 Install
  • 安装完成后，左侧边栏会出现 Claude 图标

登录

点击 Claude 图标 → 按提示登录你的 Anthropic / Claude 账号。登录成功后就可以在 VS Code 内直接和 Claude 对话了。

Claude Code 能做什么？ 它可以读你打开的文件、搜索整个项目、在终端里执行命令、直接编辑代码。你只需要用自然语言告诉它你想做什么。
03 打开项目 + 熟悉界面

打开项目文件夹

方法 A：VS Code → File → Open Folder → 选择 ~/Desktop/Tencent_Project/TAAC2026

方法 B：Terminal 里执行 code ~/Desktop/Tencent_Project/TAAC2026

VS Code 界面布局

  • 左侧文件树 — 浏览所有文件夹和文件（和 Finder 一样但更方便）
  • 中间编辑区 — 打开的代码文件在这里显示
  • 下方终端 — 按 Ctrl + `（反引号）打开内置终端，直接跑命令
  • 左侧 Claude 图标 — 点击打开 Claude Code 面板，在右侧显示
推荐布局：左边文件树 + 中间代码 + 右边 Claude Code 面板 + 下面终端。这样你可以一边看代码一边问 Claude，Claude 的回答和代码修改实时可见。
04 用 Claude Code 读懂代码

在动手改任何东西之前，先让 Claude 帮你理解代码结构。

问 Claude 读代码（示例对话）

打开 Claude Code 面板，直接用自然语言提问：

# 理解整体结构 你: 帮我看看 Interformer/v0.1/ 这个文件夹，总结一下每个文件的作用 # 理解模型架构 你: 读一下 model.py，告诉我 PCVRInterFormer 的三个主要模块是什么 # 理解训练配置 你: 看看 run.sh 里用了什么超参数，和 train.py 的默认值对比一下 # 找 Bug 你: 检查 model.py 里有没有参数被 del 删掉导致不生效的问题 # 对比两个版本 你: 对比 v0.1/model.py 和 v0.5/model.py 的差异
技巧：Claude Code 可以同时读多个文件。你可以说"对比 v0.1 和 v0.3 的 train.py 有什么不同"，它会自动打开两个文件分析差异。
05 配置 Python 环境

跑代码之前需要确保 Python 环境和依赖库就绪。

检查 Python 版本

在 VS Code 的终端里运行：

python3 --version # 需要 3.9+ pip3 --version

安装依赖

TAAC2026 项目需要的核心依赖：

# 核心依赖 pip3 install torch torchvision pip3 install pyarrow pandas numpy pip3 install tensorboard pip3 install scikit-learn # 如果你的 Mac 没有 NVIDIA GPU（大部分 Mac 都没有） # 你可以在本地用 CPU 跑 demo 数据（1000 行）做功能验证 # 真正的全量训练需要在 GPU 服务器上进行

选择 Python 解释器

VS Code 底部状态栏会显示当前的 Python 版本。点击它可以切换。确保选的是安装了上述依赖的那个 Python。

重要：你的 Mac 没有 NVIDIA GPU，无法在本地做全量训练（需要 12-16 GB VRAM）。本地只能用 demo 数据（1000 行）做功能验证。全量训练要在你们队的 GPU 服务器上跑。
06 跑通 Baseline（本地 Demo）

先在本地用 1000 行 demo 数据验证代码能跑通，然后再上 GPU 服务器。

Step 6.1 — 进入实验目录

cd ~/Desktop/Tencent_Project/TAAC2026/Interformer/v0.1

Step 6.2 — 用 demo 数据跑一次

修改 run.sh 里的数据路径，指向 demo 数据：

# 在 Claude Code 里说： 你: 帮我修改 run.sh，把 data_dir 指向 ../data/demo_1000.parquet 所在的目录， schema_path 指向 ../data/schema.json， ckpt_dir 和 log_dir 都设成 ./output

Step 6.3 — 启动训练

# 在 VS Code 终端里执行 bash run.sh # 如果报 CUDA 错误（Mac 没有 GPU），加上 CPU 模式： CUDA_VISIBLE_DEVICES="" python3 train.py \ --data_dir ../data \ --schema_path ../data/schema.json \ --ckpt_dir ./output/ckpt \ --log_dir ./output/log \ --batch_size 32 \ --num_workers 0 # batch_size 调小（32），num_workers 设 0（Mac 兼容）

Step 6.4 — 看到这些输出说明跑通了

训练开始后你会看到类似这样的日志：

05/09 20:30:15 - 0:00:05 - Loading schema from ../data/schema.json 05/09 20:30:16 - 0:00:06 - Model: PCVRInterFormer, params: 239,158,977 05/09 20:30:20 - 0:00:10 - Step 10 | loss=0.6931 | lr=1.0e-04 05/09 20:30:25 - 0:00:15 - Step 20 | loss=0.5432 | lr=1.0e-04
如果报错怎么办？ 直接把错误信息复制给 Claude Code："我跑 bash run.sh 报了这个错，帮我看看怎么解决"。Claude 会读你的代码和错误信息，给出修复方案。
07 用 Claude Code 调试 & 改代码

这是 Claude Code 最强大的场景：帮你改超参、修 Bug、加新功能。

场景 A — 修改超参数

你: 帮我把 run.sh 里的 batch_size 从 256 改成 512， loss_type 改成 focal，focal_alpha 设 0.25 # Claude 会直接修改文件，你会看到 diff 预览 # 确认没问题后点 Accept

场景 B — 修 Bug

你: model.py 第 480 行有个 del seq_encoder_type 导致参数不生效， 帮我去掉这个 del 语句，保留 seq_encoder_type 参数 # Claude 会定位到那一行，提出修改方案

场景 C — 加新功能

你: 在 dataset.py 里加一个 _build_item_freq_map 方法， 扫描训练集统计每个 item_id 的出现频次， 然后用 log(1+count) 作为 item_dense 特征注入 # Claude 会写完整的代码，你审核后 Accept

场景 D — 分析训练日志

你: 看看 output/log 里的训练日志， 分析 loss 是否在下降、AUC 是否在提升、 有没有过拟合的迹象
黄金法则：你不需要自己写代码。告诉 Claude 你想要什么效果，它写代码 → 你审核 → Accept 或要求修改。这比自己从零写快 10 倍。
08 推送结果到 GitHub

代码改好、训练跑完后，把结果推到 GitHub。

方法 A — VS Code 图形界面（推荐新手）

  • 左侧栏点击 源代码管理（分支图标）
  • 看到所有改动的文件列表
  • 点每个文件可以看 diff（改了什么）
  • 在顶部输入 commit message（如 "feat: add item freq feature"）
  • 点 ✓ Commit
  • 点 Sync Changes（或点 ... → Push）

方法 B — 终端命令

# 在 VS Code 终端里执行 cd ~/Desktop/Tencent_Project/TAAC2026 # 查看改了什么 git status # 添加所有改动 git add -A # 提交（写清楚改了什么） git commit -m "feat: add item log-frequency feature to dataset.py" # 推送到 GitHub git push # 如果推送失败（网络问题），开 VPN 后重试

方法 C — 让 Claude Code 帮你

你: 帮我 git add 所有改动，commit message 写 "feat: add item freq feature to v0.3.1"，然后 push # Claude 会在终端里执行这些命令
09 实战工作流速查

日常开发时的典型操作流程。

每日开发流程

  • 开始前： git pull 拉最新代码（队友可能更新了）
  • 改代码： 在 VS Code 里改，或让 Claude Code 帮你改
  • 本地验证： 用 demo 数据跑一下确认不报错
  • 上 GPU 服务器： 把代码传到服务器跑全量训练
  • 分析结果： 训练完拿回 AUC/Loss 图，让 Claude 帮你分析
  • 提交： git add → git commit → git push
你想做的事对 Claude Code 说
理解代码"读一下 model.py 里的 PCVRInterFormer 类，解释架构"
改超参数"把 run.sh 里 batch_size 改成 512"
修 Bug"训练报了这个错 [粘贴错误]，帮我修"
加功能"在 dataset.py 加一个贝叶斯平滑 CTR 特征"
分析结果"看看训练日志，AUC 有没有在提升"
对比版本"对比 v0.1 和 v0.5 的 model.py 差异"
写 README"帮这个文件夹写一个 README.md"
推到 GitHub"git add 所有改动，commit 并 push"
GPU 服务器注意事项：如果你们用的是腾讯的 GPU 服务器（通过比赛平台），代码需要通过平台上传。如果是自己的 GPU 服务器，可以用 scp 或 rsync 把代码传过去。具体问你的同学 ZeSong，他之前一直在跑训练。
