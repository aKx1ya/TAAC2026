01 / The Problem

Two paradigms.
One recommendation task.

Feature Interaction

Static features → cross products

Captures rich cross-feature dependencies over user/item attributes through factorization, attention, or MoE.

DeepFM  ·  DCN  ·  Wukong  ·  AutoInt
How do we
unify them?
Sequential Modeling

Behavior histories → temporal patterns

Exploits the ordering of historical user actions through recurrent or attention-based encoders.

DIN  ·  SASRec  ·  HSTU  ·  TWIN
i Shallow interaction. Most pipelines combine the two only at the final prediction layer.
ii Inconsistent objectives. Sequential branches use auxiliary losses, complicating joint training.
iii Limited scalability. Recommender architectures plateau quickly with added capacity.
iv Engineering complexity. Two heterogeneous code paths inflate deployment costs.
02 / The Testbed

TAAC 2026 Academic Track

A controlled testbed of fully anonymized Tencent advertising impressions, providing one of the largest publicly accessible CTR datasets with rich behavioral structure.

Key finding from schema analysis: Eight (key, value)-aligned column pairs encode user interest at five hierarchical granularities — from 5 coarse categories to 1,473 fine ones. This structure is not exploited by the official baseline.
Schema Insight

A pyramid of user interest.

Among the 120 columns, eight (key, value)-aligned pairs map the same user across five granularities — from coarse categories to fine entity-level behavior. The baseline collapses this hierarchy into a flat dense vector.

03 / Baseline Architecture

PCVRHyFormer
Three token streams, query-mediated fusion

  • NS NS tokens aggregate static user/item features through a RankMixer-style tokenizer.
  • S Sequence tokens are tokenized per-domain — no cross-domain ID sharing.
  • Q Query tokens mediate fusion: they read from sequences, then mix with NS in a shared block.
⚠ Limitation · Query-mediated bottleneck + rigid D mod T = 0 constraint
04 / Our Approach

PCVRInterFormer
Two streams, direct modulation, no query bottleneck

  • A Cross-Domain Summary — two learnable queries (CLS + PMA) aggregate behavior across all 4 domains into the NS stream.
  • B Personalized FFN — NS context modulates each sequence position via FiLM-style gating, eliminating query tokens.
  • C Gated output fusion learns the optimal balance between NS and sequential signals.
✓ Half the model dimension · No query bottleneck · No D mod T constraint
05 / Key Mechanism

Personalized
Feed-Forward Modulation

Each sequence position is conditioned on the user's static context — a FiLM-style modulation that lets static features directly shape sequence processing without an intermediate query bottleneck.

PFFN(x, c)  =  FFN(x  ⊙  σ(Wgc)  +  Wbc)

x — sequence token

Per-position behavioral embedding from one of four domains.

c — NS context

Static user/item summary derived from the NS stream via gated mean pooling.

σ(Wgc) · gate

Learned gating + bias scale how strongly static context modulates each position.

Inspired by FiLM (Perez et al., 2018) — feature-wise linear modulation, originally for visual reasoning, adapted here for sequential CTR prediction.

07 / What We Learned

The bottleneck
is features, not training.

01

Compound, not additive.

v0.3 modified three variables simultaneously — loss, batch size, and embedding regularization. The −0.0029 AUC regression couldn't be attributed to any single change. Lesson: ablate one variable at a time.

02

Training tricks have a ceiling.

v0.5 added DHEN, DCN, GradScaler, warmup — and reached 0.852 AUC peak before overfitting to 0.760. GAUC stayed near zero. The model captures user-level signal but can't rank within a user. Feature engineering is the next frontier.

08 / Where Next

Three directions,
one open question.

  • i
    Hierarchical interest-weighted embedding.
    Exploit the eight (key, value)-aligned column pairs as a five-level interest pyramid — the schema's most under-utilized signal.
  • ii
    Cross-domain ID sharing.
    Determine whether the four behavioral domains operate over a common item vocabulary, enabling shared embeddings.
  • iii
    Systematic scaling experiments.
    Test whether InterFormer exhibits more favorable scaling behavior than HyFormer as model dimension grows.
